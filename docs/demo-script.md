# Meituan Together — 3 分钟 Demo 脚本

> 启动：`python3 server.py`，浏览器打开 `http://127.0.0.1:8000`  
> 可选 Key：`.env` 中配置 `DEEPSEEK_API_KEY` 或 `GEMINI_API_KEY`

---

## 自动演示（推荐彩排）

| URL 参数 | 效果 |
|----------|------|
| `?script=reject` | 自动 AI 匹配 → 进聊天 → 模拟拒人 → AI 换人重算 |
| `?script=budget` | 自动 AI 匹配 → 进聊天 → 「预算有点高」→ 对方同意 → 重分配 |

示例：`http://127.0.0.1:8000/?script=reject`

---

## 手动演示（约 3 分钟）

### 1. 地图 · POI-first（45s）

1. 打开 **地图**，点一个韩餐 Pin  
2. 展示 Bottom Sheet：**头图、评分、团购、当前成局需求**  
3. 点 **「我也想去」** 或 **「AI 帮我找搭子」**

### 2. AI 成局助手（60s）

1. 输入或点快捷：**韩餐 1v1**  
2. 看 **L0 规则解析** +（有 Key 时）**L2 Agent 导演**  
3. 展开 **方案对比表**、**为什么推荐**  
4. **选择这个搭子**

### 3. 成局确认室（60s）

1. 看对方 **信誉分**、方案卡  
2. 点 **模拟对方拒绝** → 读 AI **重算分** 消息 → **接受候补方案**  
   - 或点 **预算有点高** / **时间短一点** → 对方同意 → AI 推新店  
3. **我确认** → 锁定诚意金 → 双方确认

### 4. 成功页 · 闭环（30s）

1. 成局成功 → **履约时间线**  
2. **AI 排序选择团购券** → 模拟购买  
3. **导航出发**

### 5. Profile（15s）

1. 底部 **我的** → 头像、昵称、**信誉分**

---

## 答辩话术要点

- **不是社交 App**：地图上的是「店上的成局机会」，不是附近的人  
- **规则为真相源，AI 增强解释**：匹配分本地算，LLM 校准意图与话术  
- **异常可演示**：拒人换人、改预算/时间重分配、诚意金与团购闭环
